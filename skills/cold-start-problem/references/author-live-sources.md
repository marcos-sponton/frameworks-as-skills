# The Cold Start Problem — Andrew Chen's live sources

> **Live sources** = places where Andrew Chen publishes new material regularly. This file is the index into all of them, organized by source type and by topic. It's designed for the skill to jump to the specific essay / podcast / thread that matches the user's situation.
>
> **Why it matters:** Chen is one of the most active essayists in the growth / network-effects community — ~650+ essays across two decades, weekly-ish Substack cadence, active on Twitter/X, regular a16z posts, and constant podcast rotation. The book is 2021; the framework has been refined and stress-tested continuously since. **Skipping live sources = the skill drifts out of date within a quarter.** Community PRs to this file are the fastest way to keep the skill current.
>
> **How to use in a session:** when the user has a specific situation (AI-era defensibility, agents-for-X, gaming networks, marketplace launches, ceiling diagnosis, cherry-picking risk), scan this index for the matching item and either (a) suggest they read/listen, or (b) WebFetch it inline if depth is needed.
