# Playing to Win — Roger Martin's live sources

> **Live sources** = places where Roger Martin publishes new material regularly. This file is the index into all of them, organized by source type and by topic. It's designed for the skill to jump to the specific essay/video/podcast that matches the user's situation.
>
> **Why it matters:** Playing to Win is not frozen in 2013. Martin updates his thinking continuously. Skipping his live sources = the skill drifts out of date. Community PRs to this file are the fastest way to keep the skill current.
>
> **How to use in a session:** when the user has a specific situation (offsite, chief strategy officer decision, HTW stuck, pivot question, WWHTBT device), scan this index for the matching item and either (a) suggest they read/watch it, or (b) WebFetch it inline if depth is needed.
