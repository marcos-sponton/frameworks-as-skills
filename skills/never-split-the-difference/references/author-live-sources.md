# Chris Voss's live sources

> **Live sources** = places where Chris Voss (or the Black Swan Group he founded) publishes new material regularly. This file is the index into all of them, organized by source type. It's designed for the skill to jump to the specific essay / talk / newsletter / podcast that matches the user's situation.
>
> **Why it matters:** Voss's teaching is not frozen at the 2016 book. The MasterClass came in 2020, *The Full Fee Agent* in 2022, and the Negotiation Mastery Newsletter (formerly *The Edge*) has been publishing weekly for a decade. Skipping his live sources = the skill drifts out of date. Community PRs to this file are the fastest way to keep the skill current.
>
> **How to use in a session:** when the user has a specific situation (salary negotiation, real-estate fee defense, discount pushback, hard conversation prep, Ackerman planning), scan this index for the matching item and either (a) suggest they read/watch/listen, or (b) WebFetch it inline if depth is needed.
