# DORA / Accelerate — Nicole Forsgren's live sources

> **Live sources** = places where Forsgren (and the surrounding research community — DORA team, DX Inc., Storey lab, Noda) publish new material regularly. Designed for the skill to jump to the specific source that matches the user's situation.
>
> **Why it matters:** DORA is not frozen in 2018. The State of DevOps report evolves every year. Reliability was added in 2021, security in 2022, AI in 2024. SPACE is 2021. DevEx is 2023. DX Core 4 is 2024. Frictionless is 2025. Skipping the live sources = the skill drifts out of date. Community PRs to this file are the fastest way to keep the skill current.
>
> **How to use in a session:** when the user has a specific situation (a specific DORA question, a specific AI-era question, an executive metrics decision, a friction diagnosis), scan this index for the matching item and either (a) suggest they read/watch it, or (b) WebFetch it inline if depth is needed.

## Fuente principal (research org) — DORA / dora.dev

**Live URL:** [https://dora.dev/](https://dora.dev/)

Google-hosted since the 2018 acquisition. Continues to produce the annual *State of DevOps* report and maintain the capabilities catalog.

Key pages:
- **[dora.dev/quickcheck](https://dora.dev/quickcheck/)** — free assessment tool; returns tier estimate + specific capability recommendations. Best starting point for any team.
- **[dora.dev/capabilities](https://dora.dev/capabilities/)** — the current 30+ capabilities catalog with implementation guidance per capability.
- **[dora.dev/guides/dora-metrics-four-keys/](https://dora.dev/guides/dora-metrics-four-keys/)** — canonical definitions of the current five-metric model.
- **[dora.dev/research](https://dora.dev/research/)** — all *State of DevOps* reports back to 2014.

Annual reports (most recent first):
- **[2024 State of DevOps Report](https://dora.dev/research/2024/dora-report/)** — the AI report. Essential reading right now.
- 2023 — Documentation identified as top under-invested capability.
- 2022 — Security integrated throughout SDLC.
- 2021 — Reliability added as fifth measure.
- 2019 — Elite doubled year-over-year.
- 2014 — the first year.

## Fuente principal (books)

- **[*Accelerate: The Science of Lean Software and DevOps*](https://itrevolution.com/product/accelerate/)** — Forsgren, Humble, Kim (2018). The canonical text. Shingo Research Award 2019.
- **[*The DevOps Handbook*, 2nd ed.](https://itrevolution.com/product/the-devops-handbook-second-edition/)** — Kim, Humble, Debois, Willis, Forsgren (2021). Broader DevOps context.
- **[*Frictionless: 7 Steps to Remove Barriers, Unlock Value, and Outpace Your Competition in the AI Era*](https://www.amazon.com/Frictionless-Remove-Barriers-Outpace-Competition/dp/1662966377)** — Forsgren, Noda (Dec 2025). The most recent Forsgren book — focused on AI era, friction removal, executive playbook.
- **[developerexperiencebook.com](https://developerexperiencebook.com/)** — the Frictionless book site.
