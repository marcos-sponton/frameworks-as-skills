# 7 Powers — Sources

> Every source consulted while building this skill, with links. Users should be able to verify anything the skill says.

## Primary text

- **7 Powers: The Foundations of Business Strategy** — Hamilton Helmer, Deep Strategy LLC, 2016. [Amazon](https://www.amazon.com/7-Powers-Foundations-Business-Strategy/dp/0998116319) · [7powers.com (book site)](https://7powers.com/). The canonical source. Read it.

## Authoritative institutional sources

- **Strategy Capital** — Helmer's investment firm; operationalizes 7 Powers as an investing method ("Power Dynamics"). [https://strategycapital.com/](https://strategycapital.com/) · [About](https://strategycapital.com/about/).
- **Strategy Capital — Media page** — the canonical index of every Helmer podcast/interview appearance. [https://strategycapital.com/media/](https://strategycapital.com/media/).
- **7powers.com** — the book's marketing site. Synopsis, foreword, endorsements (Ek, Hastings, Thiel, Chizen, Levin), and a Reed Hastings + Helmer YouTube video. No blog. Static since 2016.

## What this skill did NOT consult (gaps)

Being explicit so users can PR to close them.

- **Full text of the 2016 book** was not re-read line-by-line during skill build — only summaries, quote extractions from Blas.com and other secondary notes, and direct quotes cited in interviews. A pass with the book in hand would sharpen a few edges.
- **Second Invention book manuscript** — not yet published; the current corpus on Second Invention is limited to the Trium Group interview and the Acquired 2023 episode.
- **Chenyi Shi's individual appearances / writing** — Shi is Helmer's collaborator but has less individual public output. Any solo appearances by Shi would enrich the skill.
- **Institutional videos** — Stanford lectures, conference keynotes not indexed here.
- **Any Helmer podcast appearances after Lenny (May 2024)** — the corpus is current as of ~mid-2024. New appearances should be added to `author-live-sources.md`.
- **AI-era commentary by Helmer directly** — thin in the corpus. Third-party applications to Nvidia / TSMC / ASML are useful but tagged as *applied*.
- **A.G. Buffett / Charlie Munger writings** — informal parent metaphor ("economic castles / moats"); useful reference not fully consulted here.
- **Community critiques and case applications** — practitioners applying 7 Powers in the wild often surface gotchas and edge cases Helmer doesn't. PRs welcome.
