# Challenger + JOLT — Prompt templates

> Copy-paste templates users can adapt. Each starts with a user situation and invokes the skill in a shape Claude or Codex can execute well.

## Deal review — run one active opportunity through Challenger + JOLT

```
Please run this active deal through the Challenger + JOLT frameworks.

Deal context:
- Company: {{customer name / describe}}
- ACV / deal size: {{estimate}}
- Stage: {{early / mid / late}}
- Buying committee (as I understand it): {{list roles}}
- My champion: {{name and role — describe what they've done}}
- Current status: {{sentence — "moving", "quiet", "asked for X"}}
- Reason I'm asking now: {{stalled / next-step-uncertainty / forecast pressure / other}}

Please:
1. Diagnose whether my "champion" is a Mobilizer or a Talker — and how to tell.
2. Diagnose whether this deal is at risk of no-decision (JOLT), competitive loss, or on track.
3. If no-decision risk: which of the three faces of indecision (valuation / information / outcomes) is most likely dominant, and how would you probe?
4. Recommend specific next-move plays from the JOLT sequence (J-O-L-T), tailored to the diagnosis.
5. Push back if I'm reaching for FOMO / discount / more content — cite the research.
```

## Lost-deal post-mortem — run the JOLT diagnostic

```
Here's the story of a deal we just lost. Please critique the post-mortem.

The story:
{{2-4 paragraphs — what happened, why we think we lost, what the CRM says}}

Please:
1. First question: did the customer actually purchase from anyone? If not, this is a no-decision loss, not a competitive loss — reset the diagnosis.
2. Which of the three faces of indecision (valuation / information / outcomes) most likely killed the deal?
3. What in the sales process would have caught it? Where should we have Judged earlier?
4. What Mobilizer / Talker misdiagnoses might have contributed?
5. What single change to the playbook would prevent this pattern from repeating?
```

## Pitch / deck critique — is it real Commercial Insight?

```
Here's my sales deck / pitch flow. Please critique it against the Challenger framework.

{{paste deck outline or attach}}

Please:
1. Which slide (if any) delivers Commercial Insight — a reframe of the customer's world that leads uniquely to my solution?
2. Run the 4 tests for real Commercial Insight (would the customer pay for it alone? challenge how they currently think? lead uniquely to my differentiators? teachable at scale?).
3. Where does the deck sound like a features-first / capabilities pitch instead of Insight-first?
4. Is the pitch tailored per stakeholder, or is it one broadcast?
5. What would Dixon push back on hardest? What's the strongest slide worth doubling down on?
```

## Mobilizer mapping — a specific complex account

```
Help me map the buying committee in this account using the Challenger Customer taxonomy.

The account:
- Company: {{describe}}
- What I'm selling: {{one-line}}
- Committee (as I know it):
  - {{Name / Role / What I've observed about them / How they've reacted to me so far}}
  - ...

Please:
1. Classify each stakeholder as Mobilizer subtype (Go-Getter / Teacher / Skeptic), Talker subtype (Guide / Friend / Climber), or Blocker.
2. Justify each classification from the observed behavior.
3. Which Skeptic (if any) should I invest heavily in?
4. Am I currently selling through a Talker who feels like a champion?
5. What's the single move that would most improve my position in this account this week?
```

## Rep coaching — diagnose the profile and prescribe

```
Please help me coach this rep against the Challenger framework.

Rep context:
- Role: {{AE / SDR / partner / other}}
- Segment: {{SMB / mid-market / enterprise}}
- Typical deal shape: {{ACV, cycle length, stakeholder count}}
- Observed behaviors: {{what they do well, what they do reflexively, how they handle pushback, how they handle price}}
- Performance: {{quota attainment, win rate, no-decision rate if known}}

Please:
1. Which of the 5 Challenger profiles do they default to (Challenger, Hard Worker, Relationship Builder, Lone Wolf, Reactive Problem Solver)?
2. Which Challenger behaviors (Teach / Tailor / Take Control) do they need to grow into, and in what order?
3. What Commercial Insight training would move them the most?
4. What coaching anti-pattern should I avoid (e.g., personality transplant, Lone Wolf conversion)?
5. If they're already a Challenger — what's the next-level move?
```

## Sales-playbook redesign — where to inject Challenger + JOLT

```
Here's my current sales playbook / process. Please critique it against Challenger + JOLT.

{{paste playbook outline or attach — stages, exit criteria, sales assets, review cadence}}

Please:
1. Where in the process should I be Teaching with Commercial Insight, and is the asset supporting that Teach real Commercial Insight (4 tests)?
2. Where in the process should I be Judging for indecision (before the deal stalls)?
3. Are my sales assets designed to Limit exploration or to add more content to overwhelmed buyers?

5. What's the single playbook change that would most reduce no-decision losses?
```

## Founder / partner BD — Activator pattern

```
I'm a {{founder / partner / doer-seller}} at {{describe}}. I'm doing my own BD and want to think about it through Dixon's Activator research.

Current BD context:
- What I sell: {{describe}}
- Typical client / deal shape: {{describe}}
- Current BD rhythm: {{how often, what channels, what activities}}
- What's working: {{list}}
- What's not: {{list}}

Please:
1. Am I currently operating as Activator, Expert, Confidant, Debater, or Realist — and how do I know?
2. If not Activator: what's the highest-leverage move to shift?
3. What Commercial Insight should I be publishing / speaking about consistently to shape the market before buyers come to me?
4. What warm-network cultivation am I under-investing in?
5. What reactive BD habit should I kill first?
```

## FOMU check — before I send an urgency email

```
I'm about to send an urgency email / discount offer / "final call" note to a deal that's gone quiet. Before I do, please stress-test it.

The deal context:
- Where the deal is: {{late-stage / stalled / silent}}
- What I'm thinking of sending:
{{paste draft}}

Please:
1. Am I reaching for FOMO / urgency / discount on a deal that's actually stuck in indecision (FOMU)?
2. What's the likely diagnosis (three faces)?
3. What alternative move would be more likely to unstick the deal — Judge, Offer, Limit, or Take?
4. Rewrite the email in a FOMU-appropriate register if that's the diagnosis.
5. Warn me clearly if this is the ~87% of cases where urgency backfires.
```

## Compare Challenger + JOLT vs. an adjacent framework

```
I'm deciding whether to use Challenger + JOLT or {{other framework — e.g., April Dunford's Sales Pitch, Bob Moesta's Demand-Side Sales, SPIN, Sandler}} for {{my situation}}.

Help me pick. If the answer is "use both, in this sequence", tell me the sequence. If the answer is "use a different framework entirely", tell me that too.

Specifically:
1. Which framework fits my situation best given the deal shape, buying context, and where I'm stuck?
2. Are they complementary — and if so, how would they compose?
3. Where does each framework specifically NOT help me?
```
