# Four Fits — Prompt templates

> Copy-paste templates users can adapt. Each starts with a user situation and invokes the skill in a shape Claude or Codex can execute well.

## Start a Four Fits diagnostic from scratch

```
I want to run a Four Fits diagnostic on {{my company/product}}.

Context:
- Stage: {{seed / Series A / Series B / growth / mature}}
- Current ARR: {{$X}}
- Growth rate: {{Y% YoY / MoM}}
- Business model + ARPU: {{describe}}
- Top 2 acquisition channels: {{describe}}
- Retention shape: {{flattening / decaying / unknown}}
- Where I'm stuck: {{one sentence — often "growth is stalling" or "we don't know which channel to bet on"}}

Please:
1. Score each of the four fits 1-5 with specific evidence.
2. Identify the weakest link — that's where the chain breaks.
3. Propose a coordinated move that fixes the weakest link without breaking the others.
4. Cite Balfour essays when introducing specific devices (ARPU zones, threshold formula, universal growth loop).
```

## Diagnose why growth is stalling

```
Our growth has {{stalled / slowed / decayed}} in the last {{X months/quarters}}.

Context:
- What was working: {{describe}}
- What we've tried: {{describe}}
- Current metrics: {{acquisition, activation, retention, revenue}}
- Recent structural changes (pricing, product, team): {{describe}}

Apply the Four Fits framework:
1. Which specific fit is most likely broken? Score all four and name the weakest.
2. Is this a "tugboat" situation (PMF alone, missing the other three) or a specific fit collapse?
3. If we're in the AI era, has ChatGPT / LLM commoditization eaten our PMF? (Chegg-style)
4. What's the coordinated move — not a tactic, a chain-level shift?
```

## Design a growth loop from scratch

```
I need to design a growth loop for {{my product}}.

Current state:
- Product: {{describe}}
- Users are acquired mostly via: {{describe}}
- Product mechanisms that could produce loop fuel: {{list}}

Apply Balfour's growth-loop method:
1. Which of the 5 loop types (viral, content, paid, sales, UGC/SEO) best fits my product's shape?
2. Sketch the loop diagram: input → action → output → back to input.
3. Force the arrow to close — name the specific product mechanism that turns output into next-cycle input.
4. Estimate the amplification factor (>1 = compounds; <1 = decays).
5. Estimate cycle time.
6. Pre-mortem the decay: what saturates first?
```

## Critique a funnel-only growth plan

```
Here's our growth plan / growth section of our board deck:

{{paste content}}

Please critique it using Balfour's Four Fits + Growth Loops:
1. Is this a funnel or a loop? Does any output feed back to input?
2. Are all four fits addressed, or only PMF + channels?
3. Which anti-patterns are present? (growth hacks, channel-agnostic, copy-the-playbook, "we just need a growth marketer", single-leg North Star)
4. What's missing that Balfour would push on hardest?
5. Reframe as a proper Four Fits + loops plan.
```

## ARPU danger zone check

```
Our current ARPU is {{$X per year}} and we're trying to figure out our acquisition channels.

Apply Balfour's Channel-Model Fit map:
1. Which of the 5 ARPU zones am I in?
2. Which channels structurally fit my zone?
3. Am I in the Danger Zone ($100-$1k)? If yes, what's the move — up-market or down-market?
4. What would my four-fit chain look like AFTER that move? Does it hold?
```

## Model-Market Fit threshold check

```
We're targeting {{market}} with ARPU of {{$X}}.

Apply the Model-Market threshold formula:
- Estimated TAM (customer count in target market): {{Y}}
- Realistic capture rate at maturity: {{Z%}}
- Compute: ARPU × TAM × Capture% = ${{result}}

1. Does this clear $100M?
2. If yes, does 10% capture math hold up? (Balfour's SaaS sanity check)
3. If no, what would have to change: raise ARPU (which business archetype?), expand market (re-verify PMF), or accept smaller scale?
4. Which of the 5 archetypes am I: Elephants / Moose / Rabbits / Mice / Flies?
```

## AI-era stress test on an existing business

```
We built {{our company}} in the pre-AI era. I want to stress-test the four fits against the current AI landscape.

Apply Balfour's 2024-2025 AI-era reframe:
1. PMF: is our value prop "we do X faster/cheaper/better than manual" where X is now trivial for LLMs? (Chegg risk)
2. Product-Channel Fit: are our current channels (SEO, paid search) at risk from ChatGPT-as-discovery?
3. Channel-Model Fit: do our unit economics survive when we add meaningful AI features? Does freemium still work?
4. Model-Market Fit: are our buyers consolidating around AI-native alternatives?

For each fit, give a risk score (low/medium/high) with mechanism. Then propose the highest-leverage move.
```

## Should we move up-market or down-market?

```
We're currently at {{ARPU $X}} serving {{customer segment}}. We're considering moving {{up-market to $Y / down-market to $Z}}.

Apply the Four Fits chain BEFORE and AFTER the move:
1. Product-Market Fit: does the new segment have the same problem we solve? What new PMF signal do we need?
2. Product-Channel Fit: what new channels open? What channels close? What product mechanisms change?
3. Channel-Model Fit: which ARPU zone are we in before/after? Does the CAC:LTV math hold?
4. Model-Market Fit: which business archetype are we moving between (Elephants / Moose / Rabbits / Mice / Flies)?
5. Which of the four fits breaks hardest in transition? What's the mitigation?
```

## Reverse-engineer a competitor's four fits

```
Help me reverse-engineer {{competitor}}'s four fits.

Publicly observable signals:
- Product shape: {{describe}}
- Apparent channels: {{describe}}
- Pricing / ARPU: {{describe}}
- Target market: {{describe}}

1. Score their four fits based on public signals.
2. Which loops are they running? What's the amplification factor?
3. Where is their chain strong? Where is it weakest?
4. What can I learn about MY chain from theirs?
5. WARNING me if I'm about to try to copy their playbook — that only works if my chain matches theirs.
```

## Hiring the first growth leader

```
We're at {{$X ARR / stage}} and hiring our first growth leader.

Apply Balfour's Growth Machine principles:
1. Are we actually ready to hire growth? (PMF verified, retention flattening?)
2. What shape should the role be — VP Growth, Head of Growth, Growth PM, Growth Marketing? Depends on which fit is broken.
3. What's the growth team composition — product embedded, marketing embedded, or standalone pod?
4. What are the 3 candidates I should NOT hire (per Balfour's "6 mistakes growth candidates make")?
```

## Growth model for the board

```
Help me draft the growth model slide for my board deck.

Context:
- Current state (fits scored): {{paste}}
- Next-quarter plan: {{describe}}
- 12-month goal: {{describe}}

Apply Balfour's board-communication approach:
1. Show the four fits as a chain — where we are, where we're going.
2. Show the primary growth loops with amplification numbers.
3. Show the biggest risks per fit.
4. Show one number that measures the whole system (not a single-leg North Star).
5. Show the coordinated move if the biggest risk materializes.
```

## Pre-flight before invoking Four Fits

```
Before running Four Fits on my situation, help me check:

1. Am I past PMF? (If no, Four Fits is the wrong tool — send me to JTBD / continuous discovery.)
2. Am I actually chasing $100M+ scale? (If no, calibrate the framework to my ambition.)
3. Is my question strategic (which fit is broken?) or tactical (what ad copy?) — Four Fits is strategic.
4. Do I have real evidence (retention curves, CAC data, actual channel metrics), or am I working from feels?
```
