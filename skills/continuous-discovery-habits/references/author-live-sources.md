# Continuous Discovery Habits — Teresa Torres's live sources

> **Live sources** = places where Teresa Torres publishes new material regularly. This file is the index into all of them, organized by source type and by topic. It's designed for the skill to jump to the specific essay / episode / post that matches the user's situation.
>
> **Why it matters — the differential of this skill.** Torres publishes a lot, across essays + podcast + LinkedIn. Unlike Helmer (thin live output) or even Perri (rich but at slower cadence), Torres refines the method publicly in near-real time. If this index goes stale, the skill drifts out of date within months.
>
> **How to use in a session:** when the user has a specific situation (setting up cadence, story-based interview coaching, OST building, assumption mapping, POM adoption, AI + discovery), scan this index for the matching item and either (a) suggest they read/listen, or (b) WebFetch it inline if depth is needed.
