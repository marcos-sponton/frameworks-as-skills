## Adjacent authors referenced in this skill

Torres's method composes with several adjacent frameworks. Sources for each:

- **Marty Cagan / SVPG** — *Inspired* (2008/2018), *Empowered* (2020), *Transformed* (2024). [svpg.com](https://www.svpg.com/). Cagan owns the "Product Operating Model" phrase at the top-level org altitude; Torres provides the weekly practice inside. See [[inspired]] once built.
- **Melissa Perri** — *Escaping the Build Trap* (O'Reilly, 2018), *Product Operations* (with Denise Tilles, 2023). Perri explicitly endorses Torres (Product Thinking Ep 269, May 2026). See [[escaping-the-build-trap]].
- **Eric Ries — Lean Startup** — foundational influence. Torres keeps build-measure-learn but redefines MVP as "small assumption test". See [[lean-startup]] once built.
- **Bob Moesta / Jim Kalbach — Jobs to be Done** — Torres refuses to use JTBD vocabulary but the substance is compatible. See [[bob-moesta]].
- **Ryan Singer / Basecamp — Shape Up** — Compatible on delivery cadence; Torres is discovery cadence. [https://basecamp.com/shapeup](https://basecamp.com/shapeup).
- **Alexander Osterwalder / David Bland — *Testing Business Ideas*** — the assumption-test format library Torres draws on.
- **IDEO / d.school — Design Thinking** — Torres corrects the design-thinking default toward opportunity-first (rather than prototype-first).
- **Mike Rother — Toyota Kata** — parent of the "learning loop" pattern Perri also adapts.
- **Andy Grove / John Doerr — OKRs** — compatible with Torres's method with 2 constraints (product outcomes not business; team-level not individual).
- **Petra Wille — *Strong Product People*** — Torres's co-host on *All Things Product*.
