# Working Backwards — Live sources

> **Live sources** = places where Bill Carr, Colin Bryar, and Working Backwards LLC publish new material regularly. This file is the index into all of them, organized by source type and topic. It's designed for the skill to jump to the specific essay/course/podcast that matches the user's situation.
>
> **Why it matters:** unlike other framework-authors who publish essays weekly, Carr and Bryar operate mostly through their consulting firm — the post-book output is *institutional* (firm blog, courses, WBR App) more than *personal-brand* (they are not weekly-essay authors). This changes how you use the index: fewer sources, denser signal per source.
>
> **How to use in a session:** when the user has a specific situation (drafting a PR/FAQ, running a broken review, structuring an STL, designing an Operating Plan), scan this index for the matching item and either (a) suggest they read/watch it, or (b) WebFetch it inline if depth is needed.

## What they don't have

- **No Substack, no Medium, no personal blog** for either author.
- **No dedicated YouTube channel.** Talks scattered on institutional channels (Lenny, First Round, About Amazon, LAI Speakers Bureau).
- **No newsletter.** The firm blog is the closest equivalent, and it publishes in bursts rather than on a fixed cadence.
- **No AI-era commentary at essay length.** The mechanisms are portrayed as technology-neutral; if a user needs "Working Backwards for AI-native products," you're extrapolating.
