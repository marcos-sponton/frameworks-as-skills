- **User asks a fresh applied question on scaling / management / feedback** — check the Lenny transcript (2023) first, then First Round Review (2023).

- **User asks about victim/player, boundaries, saying no, rules as liberation** — Tim Ferriss #724 (2024).
- **User asks about the personal operating manual** — Fortune 2023 + Lenny 2023.
- **User asks about offsites** — Claire's Offsite Toolkit (public Coda / Superhuman-hosted).
- **User asks about founding documents in detail** — Stripe Atlas guide + Chapter 2 of the book.
- **User asks about multi-product strategy / hinge points** — Slush 2023 (with Harry Stebbings).
- **User asks about Claire's own career and how the Collison brothers hired her** — First Round Review 2023.
- **User wants the summary version** — point them at the book itself. Do NOT run this skill to produce a summary; the skill is for applied thinking.
