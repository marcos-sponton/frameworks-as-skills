# Cynefin — Dave Snowden's live sources

> **Live sources** = places where Dave Snowden publishes new material regularly. Of all the framework authors this repo covers, Snowden has by far the **most prolific live footprint** — near-daily blog posts, multiple X posts per day, the community-maintained cynefin.io wiki, a Mastodon mirror, active LinkedIn, and dozens of YouTube talks. This file is the index into all of them, organized by source type and by topic.
>
> **Why it matters:** Cynefin is not frozen in 2007. Snowden updates his thinking continuously — recent examples: the Aporetic Turn (2019–20), Estuarine Mapping (2023–24), and running commentary on any application of the framework he considers a misreading. Skipping his live sources = the skill drifts out of date. Community PRs to this file are the fastest way to keep the skill current.
>
> **How to use in a session:** when the user has a specific situation (a Complex-domain decision, a SAFe / Design Thinking / Systems Thinking claim, an Estuarine question, a probe design question, an aporetic exploration), scan this index for the matching item and either (a) suggest they read/watch it, or (b) WebFetch it inline if depth is needed.
>
> **Note:** Snowden does **not** run a Substack. Do not fabricate a Substack URL.

## Fuente principal (wiki) — cynefin.io

**Live URL:** [https://cynefin.io](https://cynefin.io) — the community-maintained canonical technical reference. Includes framework definitions, publications list, Estuarine wiki.

**Key wiki pages:**
- [Cynefin Domains](https://cynefin.io/wiki/Cynefin_Domains) — the current canonical description of the five domains, the cliff, liminality.
- [Aporetic Turn](https://cynefin.io/wiki/Aporetic_Turn) — the 2019–20 split into Aporetic and Confused, plus the five exits.
- [Constraints](https://cynefin.io/wiki/Constraints) — the three main constraint types (rigid / governing / enabling), the endoskeleton metaphor.
- [Estuarine framework](https://cynefin.io/wiki/Estuarine_framework) — the six sub-types of constraint, the two borders, the 7-step process.

The wiki is more up-to-date than the HBR paper on every technical point. When Snowden's framework has evolved and the HBR is stale, cynefin.io is the source.

## Fuente principal (video) — YouTube

Snowden has dozens of recorded talks. **Signature ones:**

- **Children's Party** — his best-known teaching story. Distinguishes ordered planning (learning objectives, milestones, motivational materials) from enabling constraints (games, boundaries, attractors). If you watch one Snowden video, watch this.
- **Rewilding Agile** (LESS Talks, 2020) — the essay-turned-talk on returning Agile to first principles and killing the industrial complex.
- **Beyond Cynefin with Dave Snowden (featuring Estuarine Mapping)** — introduction to the newest framework.
- Multiple **Estuarine Mapping talks** at Agile Tuesday and elsewhere — the fastest way to get Estuarine content since it's newer than the blog systematically covers.

Search "Dave Snowden" on YouTube — the top results are almost all worth watching.
