# Obviously Awesome — April Dunford's live sources

> **Live sources** = places where April Dunford publishes new material regularly. This file is the index into all of them, organized by source type and by topic. It's designed for the skill to jump to the specific essay/episode/talk that matches the user's situation.
>
> **Why it matters:** positioning is not frozen in 2019. The 2026 2nd edition of *Obviously Awesome* restructured the process, added a full multi-product chapter, expanded differentiated value, and added new market-category thinking. Since 2019 Dunford has also published *Sales Pitch* (2023), ~biweekly Substack essays (43K+ subscribers), and 48 podcast episodes across 3 seasons. Skipping her live sources = the skill drifts out of date. Community PRs to this file are the fastest way to keep the skill current.
>
> **How to use in a session:** when the user has a specific situation (multi-product positioning, competitor lying, AI-era positioning, running a workshop, redesigning a pitch, revisiting positioning after acquisition), scan this index for the matching item and either (a) suggest they read/listen, or (b) WebFetch it inline if depth is needed.
