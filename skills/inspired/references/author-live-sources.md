# Inspired — Author Live Sources

> The single fastest-decaying part of this skill. Cagan and SVPG publish ~weekly, sometimes 2–3 essays/week. When the user's situation matches a specific essay, consult this index and either point them to it or WebFetch inline for depth. Community PRs adding new essays keep the skill from going stale.

## Primary channel — SVPG articles hub

**URL:** [svpg.com/articles](https://www.svpg.com/articles/) — 32+ pages of essays back to 2007.
**Marty Cagan author page:** [svpg.com/author/marty/](https://www.svpg.com/author/marty/).
**Cadence:** ~weekly, sometimes 2–3/week. Cagan is the dominant voice; Chris Jones, Christian Idiodi, Lea Hickman, Martina Lauchengco publish alongside.
**Format:** short-to-medium essays (500–1500 words typically). Dense with opinion, thin on hedging.

### Canonical evergreen essays — index by topic

Load these when the topic is in the essay title. Almost all Cagan-authored unless noted.

**Product Team + PM role:**
- [Product vs Feature Teams](https://www.svpg.com/product-vs-feature-teams/) — the canonical definition of both. **Load when:** user is diagnosing whether a team is empowered or a feature team.
- [Product vs Project Teams](https://www.svpg.com/product-vs-project-teams/) — even further degraded than feature teams. **Load when:** user has no PM at all, just a project spec being executed.
- [Empowered Product Teams](https://www.svpg.com/empowered-product-teams/) — missionaries not mercenaries; teams serve customers to meet business needs. **Load when:** user is designing team charters.

**Discovery + Delivery:**
- [Product Discovery](https://www.svpg.com/product-discovery/) — the canonical intro. **Load when:** user is standing up a discovery cadence.
- [The Four Big Risks](https://www.svpg.com/four-big-risks/) — value / usability / feasibility / viability + role ownership. **Load when:** user is thinking about what to validate in discovery, or when a project failed and you're diagnosing which risk was neglected.
- [Build to Learn vs Build to Earn](https://www.svpg.com/build-to-learn-vs-build-to-earn/) (2026-04-16) — sharpened discovery/delivery distinction. Credits Jeff Patton. **Load when:** user is confused about the difference between prototypes and MVPs.
- [Build To Learn FAQ](https://www.svpg.com/build-to-learn-faq/) (2026-04-27) — follow-up FAQ.

**Product Vision + Strategy:**
- [Product Vision vs. Mission](https://www.svpg.com/product-vision-vs-mission/) — the definitional distinction. **Load when:** user has a mission statement and calls it a vision.
- [Product Vision FAQ](https://www.svpg.com/product-vision-faq/) — the visiontype, horizons, persuasion frame.
- [Product Strategy — Overview](https://www.svpg.com/product-strategy-overview/) — focus + insights + actions + active management.
- [Product Strategy — Focus](https://www.svpg.com/product-strategy-focus/) — saying no to the hundred other good ideas.

**Roadmaps:**
- [The Alternative to Roadmaps](https://www.svpg.com/the-alternative-to-roadmaps/) — product vision + business objectives + high-integrity commitments. **Load when:** user is trying to "fix" the roadmap.
- [Roadmap Alternative FAQ](https://www.svpg.com/roadmap-alternative-faq/) — the follow-up FAQ addressing common objections.

**The umbrella:**
- [The Product Operating Model: An Introduction](https://www.svpg.com/the-product-operating-model-an-introduction/) — the canonical POM definition + three dimensions. **Load when:** user mentions POM by name, or is asking what the SVPG frame *is* at the top level.

**Coaching + Leadership:**
- [Product Coaching](https://www.svpg.com/product-coaching/) — SVPG's page on coaching, coach network, when a company needs one.

**Transformation:**
- [Transformation Series](https://www.svpg.com/transformation-series/) — running index of transformation-related essays that fed *Transformed*, still updating.

### Recent essays (2025 → July 2026) — the current live edge

Load these when the user's question intersects a recent theme. Cagan-authored unless noted.

- **[Great Products, Bad Companies](https://www.svpg.com/great-products-bad-companies/)** — 2026-06-30. Governance capture; endorses Ries's *Incorruptible*. **Load when:** user is a founder worried about long-term company preservation.

- **[Commercial vs Internal Products](https://www.svpg.com/commercial-vs-internal-products/)** — 2026-04-09. POM applies to both, with meaningful differences. **Load when:** user is running an internal-tools product org.
- **[Product Coaching and AI](https://www.svpg.com/product-coaching-and-ai/)** — 2026-02-04. Explicit reversal on 20-year human-coaching-only position. **Load when:** user is asking whether AI can serve as a product coach (yes, per Cagan 2026).
