# DHM Model — Invocation Prompts

> Templates for common tasks. Copy and adapt for your situation.

## 1. Score an initiative on DHM

Use when: evaluating a specific product initiative or feature.

```
We're considering building [initiative]. Help me evaluate it using Gibson Biddle's DHM Model.

Context:
- Our product: [what it is, who it's for]
- The initiative: [what we want to build]
- Current competitive landscape: [who else does this]
- Our current hard-to-copy advantages: [brand, network effects, scale, unique tech — if any]

Score this initiative on:
- Delight: Will customers genuinely love this? What's the evidence?
- Hard to copy: Which of the four types of hard-to-copy advantage does this build (brand, network effects, economies of scale, unique technology)? If none, how long until competitors replicate it?
- Margin-enhancing: Does this improve our financial position — not just revenue, but the spread between value and cost?

Be honest if the initiative fails on one or more dimensions. If it delights but isn't hard to copy, say so.
```

## 2. Build a Strategy/Metric/Tactic lock-up

Use when: the team has strategies but hasn't connected them to metrics and projects.

```
Help me build a Strategy/Metric/Tactic lock-up for our product using Biddle's framework.

Our product: [what it is]
Our current product strategies (or candidate strategies): [list them]
Our high-level engagement metric: [e.g., monthly retention, weekly active usage]

For each strategy, help me define:
1. The strategy hypothesis: "We believe that [strategy] will delight customers in a hard-to-copy, margin-enhancing way because [reasoning]."
2. The proxy metric: a leading indicator that's easier to move than [high-level metric] and that we believe correlates with it.
3. The tactics: 2-3 specific projects/experiments that would test this strategy.

Challenge me if a proxy metric seems like vanity. Help me think about whether the correlation is real or assumed.
```

## 3. Define proxy metrics for a strategy

Use when: the team knows their strategy but can't figure out how to measure it.

```
We have a product strategy: [strategy description].

Our high-level engagement metric is [e.g., monthly retention, NPS, weekly active usage].

Help me define proxy metrics using Biddle's framework:
1. What lower-level metrics would be leading indicators of success for this strategy?
2. Are these metrics faster to move than [high-level metric]?
3. Is there a plausible correlation between the proxy and the high-level metric?
4. How would we A/B test whether moving the proxy actually moves the high-level metric?

Give me 2-3 candidate proxy metrics, ranked by sensitivity and actionability.
```

## 4. Diagnose missing "H" (hard to copy)

Use when: the user's product delights but has no competitive advantage.

```
Our product [product description] has strong customer love — [evidence of delight: retention rate, NPS, qualitative feedback]. But we're worried about defensibility because [competitor situation].

Using Biddle's four types of hard-to-copy advantage, help me diagnose:
1. Brand: Do we have brand trust that would take years for a competitor to build?
2. Network effects: Does our product get more valuable as more people use it?
3. Economies of scale: Do our unit economics improve at scale in ways competitors can't match?
4. Unique technology: Do we have proprietary data, algorithms, or systems that create differentiation?

For each type, score us honestly (strong / emerging / weak / absent). Then recommend which 1-2 types we should invest in building.
```

## 5. Diagnose missing "M" (margin-enhancing)

Use when: the product delights and may be hard to copy but doesn't improve margins.

```
Our product initiative [description] scores well on Delight and Hard-to-copy, but I'm not sure it's margin-enhancing.

Current situation:
- Our cost structure: [key costs]
- Our revenue model: [how we make money]
- The initiative's expected impact on costs: [increase/decrease/neutral]
- The initiative's expected impact on revenue: [increase/decrease/neutral]

Help me evaluate:
1. Does this improve the spread between value created and cost incurred?
2. Does this improve retention (higher LTV)?
3. Does this enable pricing power?
4. Does this create a flywheel where profits can be reinvested?
5. Is there a version of this initiative that's MORE margin-enhancing without sacrificing Delight?
```

## 6. Prioritize a roadmap using GEM

Use when: the team has multiple initiatives and needs to decide what to build first.

```
We have the following product initiatives on our roadmap:
[List initiatives]

Using Biddle's GEM model, help me prioritize:
1. Score each initiative on expected impact to Growth, Engagement, and Monetization (high/medium/low).
2. Given our current phase [pre-scale / scaling / mature], which of G, E, M should we prioritize?
3. Which initiatives should we build first based on the GEM prioritization?
4. Are there any trade-offs we should discuss? (e.g., an initiative that's great for Growth but hurts Monetization)

Also cross-check against DHM: do all of these initiatives pass the three-dimension filter?
```

## 7. Run a quarterly product strategy review

Use when: preparing for or facilitating a quarterly strategy meeting.

```
Help me prepare a Quarterly Product Strategy Meeting using Biddle's format.

Our swimlanes and current strategies:
[List swimlanes with their Strategy/Metric/Tactic lock-ups]

For each swimlane, help me structure a review:
1. Strategy: Is the hypothesis still valid? Should we continue, pivot, or kill?
2. Metric: Has the proxy metric moved? What's the trend?
3. Tactics: Which experiments ran? What did we learn?
4. Next quarter: What experiments should we run next?

Also suggest 1-2 "What would you do?" simulation scenarios to provoke strategic discussion in the meeting.
```

## 8. Extract strategy from a project list (bottom-up)

Use when: the team has a backlog but no articulated strategy.

```
Here's our current project list / backlog:
[List projects]

Using Biddle's "Working Bottom-up" approach:
1. Scan the list and identify themes. What patterns emerge?
2. Name the implicit strategies these projects represent.
3. For each emergent strategy, evaluate it on DHM: Does it delight? Is it hard to copy? Is it margin-enhancing?
4. Are there strategies the project list implies but that nobody has stated explicitly?
5. Are there projects that don't fit any strategy? Should they be cut?

Help me turn this project list into an articulated product strategy.
```

## 9. Compare two strategic paths

Use when: choosing between two different product directions.

```
We're debating between two strategic directions:

Option A: [description]
Option B: [description]

Using Biddle's DHM Model, evaluate each option:

| Dimension | Option A | Option B |
|---|---|---|
| Delight | ? | ? |
| Hard to copy | ? | ? |
| Margin-enhancing | ? | ? |

Which option scores better on the DHM trifecta? If both pass, use GEM (Growth, Engagement, Monetization impact) to break the tie. If neither passes, what would need to change?
```
