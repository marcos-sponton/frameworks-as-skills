## Academic / foundational works referenced by Eyal

- **BJ Fogg** — Behavior Model (B=MAT). Stanford Persuasive Technology Lab. The foundation for the Action phase of the Hook Model.
- **B.F. Skinner** — Variable-ratio reinforcement schedules. The behavioral psychology foundation for Variable Reward.
- **Jack Brehm** — Reactance Theory (1966). Why variable rewards must preserve user autonomy.
- **Robert Cialdini** — *Influence: The Psychology of Persuasion*. Cognitive biases leveraged in the Action phase.
- **Daniel Kahneman** — System 1 / System 2 thinking. Framework for understanding how users make decisions.
- **Norton, Mochon, Ariely** — The IKEA Effect (2012). Why users value things they've invested labor in (Investment phase).
- **Leon Festinger** — Cognitive Dissonance Theory. Why past investments make future investments more likely.
