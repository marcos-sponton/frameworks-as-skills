# Hooked — Nir Eyal's Live Sources

> **Live sources** = places where Nir Eyal publishes new material regularly. This file is the index into all of them, organized by source type and by topic. It's designed for the skill to jump to the specific piece that matches the user's situation.
>
> **Why it matters:** the Hook Model is not frozen in 2014. Eyal keeps refining, expanding (Indistractable, Beyond Belief), and responding to critics. Skipping his live sources = the skill drifts out of date. Community PRs to this file are the fastest way to keep the skill current.
>
> **How to use in a session:** when the user has a specific situation, scan this index for the matching essay/video/podcast and either (a) suggest they read/watch it, or (b) WebFetch it inline if depth is needed.
