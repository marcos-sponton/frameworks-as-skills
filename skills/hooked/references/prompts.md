# Hooked — Prompt Templates

> Copy-paste templates for common invocations. Users can adapt to their situation.

## Design a hook for a new product

```
I want to design a hook for my product using Nir Eyal's Hook Model. Here's my product: {{brief description — what it does, who it's for, how often they'd use it}}.

Please walk me through each phase:
1. Help me identify the internal trigger (use the 5 Whys).
2. Define the simplest action in anticipation of reward.
3. Design variable rewards (which type — Tribe, Hunt, Self — fits best?).
4. Create the investment phase (what does the user put in that improves the next cycle?).

Also check: does my product sit in the Habit Zone (frequency + perceived utility)?
And run the Manipulation Matrix: would I use this? Does it improve the user's life?
```

## Diagnose why engagement is dropping

```
My product is losing engagement — DAU/MAU is declining. Here's what the product does: {{description}}. Current engagement pattern: {{what you're seeing}}.

Please walk the Hook Model as a diagnostic:
1. Are the triggers still firing? Are internal triggers established, or are we still dependent on external triggers?
2. Is the action simple enough? Where's the friction?
3. Is the reward still variable? Or has it become predictable?
4. Is the investment phase loading the next trigger? Or are sessions independent?

Tell me which phase is breaking first.
```

## Audit a product for ethical hook design

```
I want to check whether my product's engagement design is ethical using Nir Eyal's Manipulation Matrix. Here's the product: {{description}}.

Please:
1. Run the Manipulation Matrix (would the builder use it? Does it improve the user's life?).
2. Check each hook phase for dark pattern risk vs. genuine value.
3. Identify where engagement might be compulsive rather than valuable.
4. Suggest redesigns if any phase crosses from hook to exploitation.
```

## Apply Indistractable to my own behavior

```
I'm struggling with distraction around {{specific context — work, phone, social media, email, etc.}}. I want to apply Nir Eyal's Indistractable model.

Please walk me through:
1. What internal triggers are driving my distraction?
2. Help me timebox my values — what should my ideal schedule look like?
3. Which external triggers should I hack back (keep vs. eliminate)?
4. What pacts (effort, price, or identity) would help me stay on track?
```

## Design onboarding using the habit path

```
My product's onboarding isn't converting users into regular users. Here's the product: {{description}}. Current onboarding flow: {{what new users experience}}.

Please apply Eyal's Habit Test:
1. Who are our habitual users? What percentage of total users?
2. What did habitual users do differently in their first 3 sessions?
3. What is the "habit path" — the sequence habitual users follow?
4. How should we redesign onboarding to accelerate new users down the habit path?
```

## Critique my product's hook

```
Here's my product's current hook design:
- Trigger: {{what triggers user engagement}}
- Action: {{what the user does}}
- Reward: {{what the user gets}}
- Investment: {{what the user puts in}}

Please critique each phase against Eyal's Hook Model:
1. Is the trigger connected to a real internal emotional state? Or is it just notifications?
2. Is the action the SIMPLEST possible behavior in anticipation of reward?
3. Is the reward genuinely variable? Which type (Tribe, Hunt, Self)?
4. Does the investment improve the product for next use AND load the next trigger?
5. Where is the hook weakest?
```

## Compare Hook Model with another engagement framework

```
I'm deciding whether Nir Eyal's Hook Model or {{other framework — e.g., BJ Fogg's Behavior Model, gamification, Atomic Habits}} is the better tool for {{my situation}}.

Help me understand:
1. What does each framework do that the other doesn't?
2. Where do they overlap?
3. Which one fits my specific situation better, and why?
4. Can I use both? If so, how do they compose?
```

## Help me find the internal trigger

```
I'm building {{product description}} and I need to identify the internal trigger — the emotional state that will drive users to my product without external prompting.

Please run Eyal's 5 Whys technique with me:
- Start with the surface behavior: "Why would someone use this?"
- Ask "why?" five times to dig to the emotional root.
- Help me distinguish between functional needs (what they want to DO) and emotional needs (what they want to FEEL).

The internal trigger should be an emotion (boredom, loneliness, uncertainty, fear, desire for connection, etc.), not a feature.
```
