# {{Framework Name}} — Prompt templates

> Copy-paste templates for common invocations. Users can adapt to their situation.

## Start a {{framework}} session from scratch

```
I want to work through {{Framework Name}} on {{my situation}}. Context: {{brief context — 3-5 sentences about the company, product, stage, current thinking}}.

Please walk me through the {{framework}} step by step. When my answers sound weak or generic, challenge them using {{Author}}'s explicit critiques.
```

## Critique a {{artifact}} I already wrote

```
Here's a {{strategy doc / roadmap / plan}} I drafted: {{paste content or attach file}}.

Please critique it against {{Framework Name}}. Specifically:
1. Which components of the framework are missing or weak?
2. Which parts sound like {{Author}}'s explicit anti-patterns?
3. What would {{Author}} likely push back on?
4. What's my strongest point that's worth doubling down on?
```

## Help me answer a specific question in the framework

```
I'm working on {{specific question — e.g., "where to play"}} for {{my situation}}. Current thinking: {{paste}}.

Push me on this specifically. What's missing? Where am I being generic? What would {{Author}} say?
```

## Compare with an adjacent framework

```
I'm deciding whether {{Framework Name}} or {{other framework}} is the better tool for {{my situation}}. Help me pick, and if the answer is "neither, use something else", tell me that too.
```
